### Análise de Urnas Eletrônicas — TRE

Análise computacional de dados relacionados ao funcionamento de **urnas eletrônicas**, com foco na identificação de atrasos, comportamento operacional e diferentes níveis de criticidade.

O projeto trabalha com dados eleitorais de **2018 e 2022**, combinando processamento de dados, análise exploratória, estatística e informações geográficas.

#### Principais aspectos

* processamento e organização de dados;
* análise de registros de log;
* classificação por níveis de criticidade;
* identificação e estudo de atrasos;
* análise de urnas de contingência;
* comparação entre modelos de equipamentos;
* análise espacial e geográfica;
* comparação entre diferentes eleições.

#### Stack

`Python` `Pandas` `NumPy` `SciPy`
`GeoPandas` `Folium` `Plotly` `Streamlit`

<br/>

[![Repository](https://img.shields.io/badge/Repository-0d1b2a?style=for-the-badge\&logo=github\&logoColor=e2c97e)](https://github.com/Gabriel-CS/TRE)

<td width="50%" valign="top">

### Dashboard UFS–TRE

Dashboard interativo desenvolvido para **exploração e visualização dos dados de urnas eletrônicas**, transformando os resultados das análises em uma interface acessível e interativa.

A aplicação reúne diferentes módulos de análise, permitindo investigar criticidade, modelos de equipamentos e distribuição geográfica dos dados.

#### Principais aspectos

* desenvolvimento de dashboard com Streamlit;
* indicadores e KPIs;
* filtros interativos;
* visualizações com Plotly;
* mapas interativos;
* análise geoespacial;
* comparação entre modelos de urnas;
* exploração dos níveis de criticidade;
* análise das eleições de 2018 e 2022.

#### Stack

`Python` `Streamlit` `Pandas` `Plotly`
`GeoPandas` `Folium` `SciPy`
